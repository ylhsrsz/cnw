# 页眉页脚规范

**适用对象：** `提交目录_2308` 中的全部正式说明文档

**创建者学号后四位：2308**

## 1. 首页要求

首页必须体现以下信息：

- 课程名称：2026 春季计算机网络课程实习
- 文档名称：网络抓包操作说明文档
- 创建者学号后四位：2308
- 提交目录名称：`提交目录_2308`
- 提交日期

首页推荐排版如下：

```text
2026 春季计算机网络课程实习
网络抓包操作说明文档

创建者学号后四位：2308
提交目录：提交目录_2308
提交日期：____-__-__
```

## 2. 页眉统一格式

正文页、附录页、任务页统一使用以下页眉：

```text
2026春计网课程实习抓包说明 | 创建者学号后四位：2308
```

使用建议：

- 放置于页面顶部居中或顶部右侧；
- 字号略小于正文标题；
- 全部任务文档使用同一页眉格式，不得混用。

## 3. 页脚统一格式

正文页、附录页、任务页统一使用以下页脚：

```text
创建者：2308 | 页码：第 __ 页 | 提交日期：____-__-__
```

使用建议：

- 放置于页面底部居中；
- 页码需连续编号；
- 若导出为 PDF，应检查页脚是否完整显示。

## 4. 文件内标识建议

若当前阶段使用 Markdown 维护文档，建议在每个文档开头显式写出：

```text
页眉：2026春计网课程实习抓包说明 | 创建者学号后四位：2308
页脚：创建者：2308 | 页码：第 __ 页 | 提交日期：____-__-__
```

这样在后续复制到 Word 或导出为 PDF 时，可以快速套用统一格式。

## 5. 正式提交前检查

1. 首页是否出现 `2308`。
2. 页眉是否统一为指定格式。
3. 页脚是否统一为指定格式。
4. 页码是否连续。
5. 文档导出后是否存在页眉缺失、页脚被遮挡、首页未标注学号等问题。
