# Wireshark 过滤器说明

**创建者学号后四位：2308**

## 1. Task1 TCP 过滤器

```text
tcp.port == 9001
```

如服务端实际监听端口不是 `9001`，请替换为实际端口。

可选辅助过滤：

```text
ip.addr == 127.0.0.1 and tcp.port == 9001
```

## 2. Task2 UDP 过滤器

```text
udp.port == 9002
```

如服务端实际监听端口不是 `9002`，请替换为实际端口。

可选辅助过滤：

```text
ip.addr == 127.0.0.1 and udp.port == 9002
```

## 3. 使用建议

1. 先用端口过滤缩小范围；
2. 再结合时间戳和日志定位关键报文；
3. 关键截图建议至少包含：
   - 报文列表区；
   - 报文详情区；
   - 时间戳与端口信息；
   - 过滤表达式输入栏。
